# The 78 tarot cards, matched to the shared archetypes (lib/archetypes-data.ts), one to three archetypes a card.
# DRAFT written 2026-10-15 by Claude for the user to review. Nothing reads this file yet: it is not in the database.
# Format and the meaning of each basis: lib/symbol-archetype-map.ts. Order matters: the first link is the card's primary archetype.
#
# How it was made. A card's archetype used to be only a pile of encyclopedia concepts (2,603 links, no single answer per card).
# Here each card gets a short hand-written list, chosen from the card's Pixie-Smith keywords and text (lib/cards.ts), its number
# (numerology), its suit, and, as a check, where the card's encyclopedia concepts sit (docs/tarot-archetype-draft-review.md sets
# the two side by side). Each link names what it was drawn from:
#   smith-waite  the card's Pixie-Smith keywords or text say it (upright or reversed)
#   numerology   the number of the card (Aces begin, Fives test, Tens complete ...)
#   suit         the suit's usual association (Cups feeling, Pentacles the material world, Swords thought, Wands energy)
#   encyclopedia most of the card's concepts sit under it, though the keywords do not say it outright
#   name         the card's own name
# A link says the card REACHES the archetype, upright or reversed; it does not say which side. Every link is neutral for that reason.
#
# Honest limits. The Pixie-Smith keywords in lib/cards.ts follow modern reading practice more than A. E. Waite's 1910 book, and
# authors differ. Tarot numerology and the suit correspondences are modern practice too. There is no source card yet for Waite's
# Pictorial Key (the user may want one); until there is, the bases below have no sources listed.
